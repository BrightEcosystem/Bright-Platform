# Database

Estrutura física do banco de dados da Bright Platform (PostgreSQL via Supabase).

- `migrations/` — alterações de schema, imutáveis após aplicação.
- `seeds/` — dados iniciais para desenvolvimento.
- `policies/` — políticas de Row Level Security (RLS).
- `functions/` — funções e procedures do banco.

Nenhuma migration real foi criada nesta fase (fundação técnica apenas). Ver `docs/BE-002-Arquitetura-Bright-Platform.md` §11.
