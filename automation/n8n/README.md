# Automação n8n

Workflows exportados da automação da Bright Ecosystem.

- `workflows/` — arquivos de workflow exportados (JSON).
- `credentials.example/` — exemplos de credenciais sem valores reais. Nunca versionar credenciais reais.
- `docs/` — documentação de cada workflow (objetivo, gatilho, entradas, saídas, tratamento de erro, versão, responsável).

Nenhuma integração real com n8n foi iniciada nesta fase. Ver `docs/BE-002-Arquitetura-Bright-Platform.md` §12.
